# snapshad

This is a Next.js project for a video downloader app.

## Getting Started

```bash
npm install
npm run dev
```

Open http://localhost:3000 in your browser.

## Production build

```bash
npm run build
```

## Notes

- Uses Next.js App Router
- Includes a media API route for downloading public video URLs
- Keeps generated folders and local env files out of version control through .gitignore
